## Завдання 1

Пояснення
- pthread_t — тип для зберігання ідентифікатора потоку.
- pthread_create() — створює новий потік.
- worker() — функція, яку виконуватиме кожен потік.
- pthread_join() — очікує завершення потоку.
- Job — структура з індивідуальними даними кожного потоку.
Чому кожен потік має власний jobs[i]?

Тому що кожен потік повинен працювати зі своїми даними. Якщо передавати всім потокам одну структуру, вони можуть одночасно змінювати її поля. Це може призвести до стану гонитви (race condition).

Чому порядок виведення змінюється?

Потоки виконуються паралельно. Операційна система самостійно розподіляє процесорний час між ними. Тому немає гарантії, який потік першим виконає printf().

## Завдання 3

Очікуваний результат - 5050

Пояснення роботи програми
Масив містить числа від 1 до 100. Ми розподіляємо його між чотирма потоками.
Кожен потік отримує власну структуру Slice, у якій зберігаються початковий індекс, кінцевий індекс і результат обчислення.

Чому немає стану гонитви?

Усі потоки читають спільний масив data, але жоден із них його не змінює. Кожен потік працює лише зі своїм окремим зрізом і записує результат у власну структуру slices[t].

Тому потоки не конфліктують під час обчислень. Після завершення всіх потоків головний потік додає їхні результати.

## Відповіді на питання для захисту

1. Які аргументи отримує pthread_create і для чого потрібен четвертий параметр?

Функція pthread_create() отримує чотири аргументи:
pthread_create(&thread, NULL, worker, &job);

- Перший — адреса змінної, у якій зберігається ідентифікатор нового потоку.
- Другий — атрибути потоку. NULL означає використання стандартних налаштувань.
- Третій — функція, яку буде виконувати потік.
- Четвертий — аргумент, який передається у функцію потоку.
Четвертий параметр дозволяє передавати потоку необхідні дані, наприклад структуру з індивідуальними завданнями.

2. Що робить pthread_join?

pthread_join() очікує завершення вказаного потоку. Завдяки цьому головна програма може дочекатися результатів роботи всіх потоків перед подальшими обчисленнями.

3. Чому для компіляції потокових програм потрібен прапор -pthread?

Прапор -pthread повідомляє компілятору та компонувальнику, що програма використовує POSIX Threads. Він забезпечує необхідні налаштування для роботи з потоками.

4. Чому порядок завершення потоків не гарантований?

Тому що операційна система самостійно планує виконання потоків і розподіляє між ними процесорний час. Через це різні потоки можуть завершувати роботу в різному порядку.

5. У чому різниця між потоком і процесом у Linux?

Процес — це окрема програма, яка має власний адресний простір і системні ресурси.

Потік — це одиниця виконання всередині процесу. Потоки одного процесу використовують спільну пам'ять, глобальні змінні та ресурси процесу, але мають власний стек і регістри процесора.

Головна відмінність полягає в тому, що процеси ізольовані один від одного, а потоки одного процесу можуть обмінюватися даними через спільну пам'ять.
